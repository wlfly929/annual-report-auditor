## 关键结论

1. **通过率 24/30 vs 30/30**（baseline vs Agent）。仅 Agent 通过：S5, M1, M2, C4, C5, C7。
2. **Agent 的输入 token 是 baseline 的 7.8 倍**（3151 → 24580），延迟中位数 1.09s → 6.03s。代价来自每轮重发完整历史、多轮检索与整页精读；这是 Agent 固有的成本结构，不是实现缺陷。（baseline 平均延迟 28.1s 被个别超时重试拉高，不代表常态）
3. **跨文档题 baseline 2/4 vs Agent 4/4**。这类题要求同时取到两份年报的数据再合并，固定管线只做一次 top-k 检索，更容易只拿到其中一份文档。
4. **页码命中率 baseline 78.3% / Agent 100.0%**。baseline 未命中预期页的题：M1, M2, C4, C5，Agent 全部命中。固定管线仍有约 22% 的目标页落在 top-k 之外，Agent 靠多轮检索把它补了回来。
5. **拒答正确率 baseline 7/7 / Agent 7/7**。拒答题考的是“不硬编”：文档里没有的数据，能不能明确说找不到而不是编一个合理数字。

## 评测局限

- **判分靠关键词**：中文表述变体多，已用基础否定词兜底拒答题，仍可能误判；宁可接受少量误判，也不引入 LLM-as-judge 的二次不确定性。
- **样本量 30 条**：足以发现系统性问题，但不足以做统计显著性结论。
- **只统计命中，不算排序质量**：`retrieval.md` 补了检索层的页码命中与要点覆盖，但仍没有 MRR / nDCG；做 Rerank 时需要补上，否则分不清“排得更前”与“只是碰巧召回”。
