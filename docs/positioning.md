# 年报核对 Agent —— 定位稿

> 用途：待并入 README 首屏。现在的 README 从"架构"讲起，16KB，面试官不会读完；作品集的前 30 行决定他继不继续看。

## 一句话

**一个"数字必须带页码"的年报核对 Agent：把年报里的数字抽成可核对的表格，每个单元格能回到原文页；同一个指标在不同章节有两个口径时，它把两个都摆出来，而不是挑一个编一个。**

## 为什么不是"文档分析 Agent"

"文档分析"是能力描述，不是问题描述。看到这六个字，第一反应是"又一个 chat with PDF"。真正的差别不在"能分析"，而在**分析结果能不能被核对**。

| | 普通 RAG 问答 | 这个项目 |
|---|---|---|
| 输出 | 一段自然语言答案 | 答案 + 每个数字的 (文件, 页码) |
| 数字来源 | 模型复述检索片段，可能拼错精度 | 必须 `read_document` 回原页核对 |
| 同一指标多口径 | 不知道存在这回事 | 主动列出两个口径及各自出处 |
| 失败模式 | 编一个"看起来合理"的数 | 明确说"年报标注不适用" |
| 验收 | 人读着像不像 | 要点关键词 + (文件, 页码) 确定性判分 |

## 四个能当场演示的场景（全部来自真实评测题，可复现）

### 1. 数字溯源
问：苏宁环球 2025 年营业收入是多少？同比？
答：1,387,372,693 元（13.87 亿），同比下降 34.59%，来源 `1225251805.pdf p.7`。
价值：基础盘。证明每个数都能点回原文，不是模型记忆。

### 2. 口径冲突（最值钱）
问：腾讯控股 2025 年所得税开支是多少？
事实：管理层讨论（p.11）写"475 亿"，报表附注（p.204/205）写"47,448 百万"——同一个数的两种列示精度。
答：两个都给出，说明是同一金额的不同精度，分别标注出处。
价值：通用 RAG 只会挑先召回的那一个，用户无从察觉这里存在口径问题。**这是"核对"区别于"问答"的地方，也是别人 demo 不出来的。**

### 3. 拒答的边界
问：苏宁环球 2025 年研发投入具体金额？
事实：年报该栏勾选"不适用"——披露了"没有研发投入"，不是"藏得深"。
答：说明年报标注不适用，而不是编一个数，也不是干巴巴一句"未找到"。
价值：幻觉是 RAG 落地的头号问题。这里把"没披露"和"没检索到"分开了。

### 4. 跨文档同指标
问：两家公司 2025 年末员工人数相差多少倍？
事实：腾讯有两个口径——集团 115,849 人（p.81），本公司正式员工 58,812+28,600=87,412（p.99）；苏宁 909 人。倍数取决于用哪个：127.4 倍 / 96.2 倍。
答：两个倍数都给，并说明口径差异。
价值：一题同时考跨文档取数、口径判断、计算，最能体现"分析"。

## 现在的验收标准 vs 下一版

现在（已跑通）：30 题，要点关键词覆盖 ≥60% + (文件, 页码) 命中；拒答题命中否定表述即通过。baseline 24/30，Agent 30/30。

下一版（关键升级）：**单元格级命中** —— `(公司, 指标, 期间, 值±容差, 单位, 页码)` 全中才算过。这才是"分析得对"，不是"文字上提到了"。

口径题的数量：30 题里有 10 道，考的不是"能不能找到"，而是"找到了该怎么判"（7 道拒答 + 3 道口径/来源优先级）。这部分是项目真正的护城河，现在只写在 `evaluation/questions.py` 的注释里，没进产品也没进 README。

## 不做什么

- 不做投资建议、不做估值。只做数字核对与对比，判断留给用户。
- 不做通用文档问答。财报之外不承诺效果——这是刻意的取舍，也是指标能守住的原因。

## 给面试官的一段话

> 我做了一个把"数字可溯源"做到单元格级别的年报核对 Agent。30 道确定性评测不请 LLM 当裁判，判分靠要点命中 + (文件, 页码) 配对。其中 10 道题考的不是检索而是口径判断——比如腾讯的员工人数有两个统计口径，两个答案都对。固定管线 24/30，Agent 30/30，代价是 7.8 倍输入 token，所以我保留 baseline 做成本对照，而不是把所有问题都无脑交给 Agent。

## 三条负结论（面试最常被追问的部分）

1. `chunk_size` 800 → 350 是**负优化**：要点覆盖 87.5% → 71.9%，页码命中反而下降。原因是块切细后同一页被切成 3~4 块，检索只召回语义最相近的那块，造成"页码对了、答案不在"。
2. **切块粒度与 k 必须同调**：只降 chunk_size 不调 k，是净损失。
3. **L2 距离与余弦相似度 top-8 完全一致**，说明向量已近似归一化——问题不在距离度量，排除掉一个常见误判方向。
